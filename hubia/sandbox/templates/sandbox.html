Auto-Capture Recommended

Opens a visible browser on the server. Log in to Qwen manually, then click "Done" when finished. Session cookies are captured automatically.

Step-by-step instructions

  1. 1 Open Qwen (https://chat.qwen.ai/) in your browser and log in.
  2. 2 Press F12 to open DevTools.
  3. 3 Go to Application → Cookies → https://chat.qwen.ai.
  4. 4 Copy ALL cookies (token, acw_tc, aui, cna, etc.) as a JSON object.
  5. 5 Paste the cookies JSON below and click "Save Cookies".

API Usage

Use the OpenAI-compatible endpoints to access Qwen models.

List available models

# List models
curl http://localhost:8089/v1/models

Chat completion (non-streaming)

# Chat completion
curl http://localhost:8089/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "qwen/qwen3.7-max",
    "messages": [{"role": "user", "content": "Hello"}]
  }'

Chat completion (streaming)

# Streaming chat completion
curl http://localhost:8089/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "qwen/qwen3.7-max",
    "messages": [{"role": "user", "content": "Hello"}],
    "stream": true
  }'
